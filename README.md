## 📌 Project Overview

An eco-impact data dashboard monitoring carbon offsets, renewable energy adoption, waste diversion metrics, and enterprise sustainability scorecards.

---

## 🚀 Key Features

- **Emissions Tracking:** Scope 1, 2, and 3 carbon emissions calculation models.
- **Sustainability Badges:** Automated audit scorecards for corporate reporting.

## 🚦 Getting Started

### 1. Clone the Repository
`ash
git clone https://github.com/chilkotiKartik/ecorapid-sustainability.git
cd ecorapid-sustainability
`

### 2. Install Dependencies
`ash
npm install
`

### 3. Run Development Server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
